# Desert Journey

**Live app at: <https://desert-journey.pages.dev>**

An interactive story about finding yourself. Through the eyes of a droid kid,
akin to *The Little Prince*, we get to know his story and travel in real time
with him in the desert to find his and our inner world.

Created by [Rodrigo Figueroa (@bidah)](https://x.com/bidah) for the
[Visko Orbis hackathon (September 2026)](https://www.visko.ai/challenge/orbis-september-2026).
Powered by [Reactor](https://reactor.inc) and [Visko Orbis](https://visko.ai).

This project was started thanks to the
[Orbis online hackathon starter](https://github.com/Visko-Platform/orbis-online-hackathon-starter)
codebase.

## What it is

The film is not pre-rendered. Every frame is generated live by
[Visko Orbis Stable](https://www.reactor.inc/models/visko-orbis-stable), a
real-time video model hosted on Reactor, in one continuous take:

1. An intro video introduces the droid kid, then the live stream takes over
   from the same frame: he walks away from the camera across the dunes.
2. At each turn he thinks out loud and asks you what to do. Two choices appear
   over the video (one is picked for you if you wait too long).
3. Your choice is sent to the running stream as a new prompt, and the world
   changes around him without a cut: a robot fox joins him, an oasis appears
   over a dune, ruins burst out of the sand ahead. He reacts to each choice
   out loud while the scene changes.
4. Wherever you go, he ends up sitting down in the sand to meditate. A closing
   thought shows on screen, the picture fades to black and the music plays
   out.

His voice is Seed Audio, cloned from the intro video's voice; the soundtrack is
a lo-fi desert song.

## Install

You need:

- [Node.js](https://nodejs.org) 20.9 or newer
- A [Reactor](https://reactor.inc) API key with access to Visko Orbis Stable

```bash
git clone https://github.com/bidah/desert-journey.git
cd desert-journey
npm install
cp .env.example .env.local
```

Put your keys in `.env.local`:

```dotenv
REACTOR_API_KEY=your_reactor_api_key
```

The key stays on the server; the browser only receives a short-lived Reactor
session token (`app/api/token/route.ts`).

## Run

```bash
npm run dev
```

Open <http://localhost:3000> and click the sun (**Start journey**). Turn the
sound on: the story is voiced.

`npm run dev` starts Next.js through a small wrapper
(`scripts/dev-with-session-cleanup.mjs`) that deletes this app's Reactor
sessions on exit and on the next start, so a crashed or restarted dev server
never leaves a live session using your capacity.

For a production build:

```bash
npm run build
npm start
```

Your Reactor account may allow only one live session at a time. If the page
says the quota is exceeded, close other tabs running the story and wait a few
seconds; the page retries on its own.

## Pages

- `/` (and `/orbis`): the Desert Journey on Visko Orbis Stable.

## Changing the story

The story played on `/` is `public/examples/desert-journey-still/story.json`,
generated by `scripts/build-desert-still.py` (prompt pieces shared with the
other stories are in `scripts/desert_prompts.py`):

```bash
python3 scripts/build-desert-still.py
```

Each scene (node) has:

- `cues`: prompts sent to the live stream, a few seconds apart. Only the
  opening prompt describes the whole world; later cues name one visible change
  and then repeat the same sentences about his facing, the desert and the
  follow camera, since each prompt replaces the previous one.
- `choices`: the two buttons, each leading to another scene.
- `voice`: the line he says as the choices appear.
- `reaction`: the line he says right after the viewer picks this scene; the
  next choices wait for it to finish.
- `ending`: the closing text, on the last scenes instead of choices.

The spoken lines are written in `seedaudio/lines.json` and rendered with Seed
Audio (see `seedaudio/README.md`); the rendered files live in
`public/examples/desert-journey-voice/`.

## How it talks to Orbis

1. `POST /api/token` exchanges the server-side `REACTOR_API_KEY` for a scoped
   session token.
2. The page connects to `reactor/visko-orbis-stable` and receives its
   `main_video` track.
3. The start image (`public/examples/desert-journey-still/first-frame.jpg`) is sent
   with `set_image`, the opening prompt with `set_prompt`, then `start`.
4. Each later cue is another `set_prompt` on the running stream; Orbis morphs
   toward it at the next chunk (about every 1.8 s) instead of cutting.

Main files:

- `components/droid-experience.tsx`: the full-screen story page (intro, voice,
  music, choices, ending).
- `hooks/use-story-runner.ts`: story timing (cues, reactions, choices).
- `hooks/use-orbis-session.ts`: the Reactor session and Orbis commands.
- `lib/story.ts`: the story format.
